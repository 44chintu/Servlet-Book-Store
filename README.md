# Servlet Book Store
A simple Book Store web application developed using Java Servlets, JDBC, and MySQL as a hands-on learning project.

 Technologies
- Java
- Jakarta Servlets
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat 10

 Features
- Register books
- View all books
- Edit book details
- Update book information
- Delete books

 Servlets
- RegisterServlet – Handles book registration.
- BookListServlet – Retrieves and displays book records.
- EditBook – Fetches existing book details.
- UpdateBook – Updates book information.
- DeleteBook – Deletes book records.

 Database
- Database: book
- Table: BookData
- Columns: ID, BOOKNAME, BOOKEDITION, BOOKPRICE
